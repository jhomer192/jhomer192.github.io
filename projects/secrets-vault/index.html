Secrets Vault

credentials agents can use, not read
Personal tool · 2026 · Private

A personal secrets manager built so AI coding agents can use credentials without printing them. Agents run commands with the secrets they need injected and scrubbed from the output; revealing a value takes a person, or Face ID on the owner's phone. A personal tool, not a product.

AI coding agents need API keys to do their work. The easy way to give them one is to paste it somewhere they can read, at which point it ends up in a transcript, a log, or a commit. This tool lets the agent use a secret while making it unlikely to print it.

How it works

  • Run, do not read: a command runs with the secrets it needs in its environment, and any secret value that shows up in its output comes back as a [REDACTED:NAME] marker instead.
  • No read command on purpose, and agents are blocked from opening the encrypted store or dotenv files directly.
  • An iPhone app behind Face ID: when it opens, every time you return to it, and before every reveal. The newest version keeps the vault key in the phone's keychain, tied to the current Face ID enrolment.
  • Scope: it stops accidental reads and secrets leaking into agent transcripts. It is not a defence against a hostile program running as the same user, and its own documentation says so.

Built with

A Python command-line tool and encrypted store · a small Zig server · an Expo React Native iPhone app with a Swift keychain module · ChaCha20-Poly1305 and Ed25519. Private, and not available to others.
