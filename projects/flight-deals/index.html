Flight Deals

fare-watch prototype, simulated prices
Side project · 2026 · Prototype, simulated prices

A prototype of a fare watcher. Set a home airport, a destination or "anywhere", a budget and dates, and it lists the fares under your budget with a 30-day price history. The public version runs on simulated prices; it is a prototype of the interface, and a banner in the app says so.

The useful part of a fare alert is the screen it lands you on: what the fare is, how it compares with the last month, and whether it is worth acting on. This prototype is that screen, built against simulated prices so the interface can be tried without an API key.

What it does

  • Watches: pick airports from an autocomplete list of 507, filter by day of the week, and set separate return dates.
  • A deal feed sorted by savings, a 30-day price line with the low, average and high for each route, and a dashboard showing the cheapest deal and the average saving.
  • Simulated prices: a seeded generator gives each route and day the same price on every visit, with the occasional 30 to 50 percent drop so there is something to find. A provider for the Amadeus API is written but not switched on in the public build.
  • Book links hand off to Google Flights or Kayak. Everything is kept in your browser: no accounts and no alerts.

Built with

React 19 · TypeScript · Vite · Tailwind v4. Front end only, with state in localStorage. Static on GitHub Pages.
