Hotel Finder

real hotels on a map, from OpenStreetMap
Side project · 2026

Pick one of 49 cities and see its hotels on a map and in a list, pulled live from OpenStreetMap. Filter by star rating, sort by distance, stars or name, then jump to Booking.com or Hotels.com with your dates filled in. It shows where the hotels are, not what they cost.

Hotel search sites lead with price and sponsored placement. Sometimes you just want to see where the hotels are: which ones sit near the place you are going, how they cluster, which street they are on. This draws that map from open data, with nothing in the way.

What it does

  • Data: one Overpass API query fetches the hotels OpenStreetMap lists in a box roughly 11 km across the city centre, capped at 200, and keeps the result for a day.
  • Star filter: OpenStreetMap records a star rating for only some hotels, so the rest are marked unknown rather than guessed.
  • Map and list side by side on Leaflet, with each pin coloured by rating.
  • Booking hand-off: every hotel links to a Booking.com or Hotels.com search with your check-in and check-out dates already set.
  • No prices. OpenStreetMap has none, and the app does not pretend otherwise.

Built with

React · TypeScript · Vite · Leaflet. Static on GitHub Pages: no backend and no API key, with hotel data from the OpenStreetMap Overpass API.

Open to anyone No account. If a search fails, the public Overpass server is busy; try again in a minute.
